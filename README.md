# Heterogeneous Hospital Management System

This project is a React-based application using Tailwind CSS, designed for hospital data management with a focus on a "Patient 360-degree Timeline."

## Project Setup
- Framework: React
- Styling: Tailwind CSS
- Icons: Lucide-react

## Structure
- `src/components`: Contains UI components like Sidebar, Timeline, SearchBar.
- `src/data`: Mock data for patient events.
- `src/App.js`: Main layout wrapper.
